# RepClub Fitness Landing Page

A responsive landing page for the RepClub Fitness app, built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Run Locally

```bash
npm install
npm run dev
```

## Check The Code

```bash
npm run typecheck
npm run build
```

## Assets

Official RepClub assets can be placed in `public/repclub-assets` using the file names listed in `public/repclub-assets/README.md`.

If those images are missing, the page uses built-in fallback visuals so the app still runs.
